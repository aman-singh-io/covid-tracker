# ⚡ COVID-19 Tracker — Real-Time Pandemic Dashboard

> Built by **Amandeep SINGH** ([@aman-singh-io](https://github.com/aman-singh-io))

## 📌 Overview

**COVID-19 Tracker** is a responsive, real-time web application designed to track and visualize global and country-specific pandemic statistics. The application fetches live epidemiological data to display critical metrics such as confirmed cases, active cases, recoveries, and deaths, helping users stay informed with up-to-date health insights.

## 🛠️ Core Technologies

* **Frontend Framework:** React.js / Modern JavaScript
* **Styling:** CSS3 / Tailwind CSS / Responsive Design
* **Data Source:** Public COVID-19 APIs (e.g., Disease.sh / Open COVID APIs)
* **Data Visualization:** Charts / Statistical Cards

## 💫 Application Features

* **Global Statistics Overview:** Instant summary cards displaying worldwide total cases, recoveries, and deaths.
* **Country-Specific Search:** Interactive search functionality to look up detailed metrics for individual countries.
* **Interactive Data Display:** Clean visual representations of pandemic trends and numerical data.
* **Responsive Interface:** Fully optimized layout ensuring seamless viewing across mobile, tablet, and desktop devices.

## 🛠️ Local Development

### Prerequisites

* Node.js version 18.x or higher
* `npm` or `yarn`

### Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aman-singh-io/covid-tracker.git
   cd covid-tracker
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run start
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
